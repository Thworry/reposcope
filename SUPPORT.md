# Support

RepoScope is a community-maintained open-source project without a service-level agreement or guaranteed response time.

For usage questions, first review the [English README](README.md), [中文说明](README.zh-CN.md), [methodology](docs/methodology.md), and [architecture](docs/architecture.md). For reproducible defects or proposals, use the matching GitHub issue form and include only public, non-sensitive information.

GitHub API availability, unauthenticated rate limits, browser policies, and a repository's content are outside RepoScope's control. A partial or low-confidence report can be correct behavior when a tree is truncated, limits are reached, downloads fail, or supported source cannot be parsed.

Security concerns must not be filed publicly. Follow [SECURITY.md](SECURITY.md).
